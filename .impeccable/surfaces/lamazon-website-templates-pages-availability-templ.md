# Daily availability

Mode: Operate. Extend existing store and rider dashboards with one clear switch
near their operational heading. Owners pause new orders; riders pause new
assignments for today. Default ON, expiry at midnight IST, early return allowed.
Keep this separate from admin suspension/disablement. Preserve accepted work;
release a rider's uncollected assignments, retain and complete picked packages.
Show explicit ON/OFF text, saved state, pending save and recoverable errors.
Disable repeated writes and update state only after confirmation. Refresh at
midnight and on returning to the tab; respect reduced motion and keyboard use.
Customers can browse closed stores with clear closed labels and disabled buying.
Server checks enforce availability; payments captured before closure must still
be recorded. Preserve established forest/ivory/lime operational UI and typography.
